## 约定

- **活文档**放 `docs/` 根或最新的日期目录；**归档**按 `YYYYMMDD/` 装。
- 跨文档引用带小节号：`docs/design.md §2.6`。
- 文件名小写 `snake_case` ASCII，日期不进文件名（在目录上）。
- 新增机制时的写法：**先改 `config/*` 数据 → 再改代码 → 最后在 `design.md` 补一段含义**。
