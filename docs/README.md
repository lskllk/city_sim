## 约定

- 跨文档引用带小节号：`docs/design.md §2.6`。
- 文件名小写 `snake_case` ASCII。
- 新增机制时的写法：**先改 `config/*` 数据 → 再改代码 → 最后在 `design.md` 补一段"是什么意思"**。
- 不写"代码落点速查"这类表 —— 代码会动，文档会烂。
