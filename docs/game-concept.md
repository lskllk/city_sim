# 游戏构思

> ## 一个视野有限的人，在一座小城里，靠关系和情报做买卖；赚够了钱，去看更大的世界。

**技术底子**：`citysim`（确定性城市模拟内核，见仓库 README）。
城里每个人都是**真的会想、会记、会打听的 agent** —— 他们看不到全知地图，
只知道**自己记得的东西**。这条约束就是我们整个游戏的来源。

---

## 一、这是什么，不是什么

| ✓ 是 | ✗ 不是 |
|---|---|
| **声誉游戏** —— 钱是记分牌，不是玩法 | 经营模拟器（把数字做大）|
| **小镇** —— 40 人左右，你能认得大多数脸 | 大都市 / 商业帝国 |
| **信息驱动** —— 你的优势来自"知道得更多、更准" | 数值驱动 / 手速驱动 |
| **慢节奏** —— 三天后才看到某个决定的后果 | 即时反馈的爽游 |
| **涌现的故事** —— 台词由 NPC 的记忆长出来 | 剧情游戏（写好的台词）|

**一句话抓人**：
> 不是"你管的东西多"，而是"**有人记得你**"。

---

## 二、你是谁

```
你是这家小超市的老板。
你有腿（能出门）· 有肚子（会饿会困）· 有手机。
你一天只有 1440 tick，四件事抢时间：
    ① 干活      收银 · 补货 · 装修 · 记账
    ② 出门      去看 / 去听 / 去打听
    ③ 维护关系  搭话 · 请客 · 回手机
    ④ 活着      吃饭 · 睡觉

最要紧的一条: 你的视野和城里每个人一样有限 ✗
   你知道自己家在哪、路怎么走；只看到"那边有个建筑"。
   你不知道别的店卖什么，不知道那些房子里有什么。
```

---

## 三、你会经历的四种时刻（这就是全部玩法）

**① 认出他**
> 门口进来一个熟脸。你知道他叫王阿姨，住街对面，每周三来买梨。
> 你知道他上礼拜来了两次都空手走了 —— 因为你那次卖光了。

**② 他记得你 —— 而且记得的是旧的**
> 你把苹果从五块降到四块五。
> 第二天只多了两个人来买 ✗ —— 因为**只有看见过或听说过的人知道**。
> 而隔壁那条街的人，记得的还是你三个月前的五块。

**③ 你听说**
> 你在店里听见两个人在议论："那家店东西挺全的，就是老板总不在。"
> 你没有插话。你把这句话记下来了。

**④ 你打听，然后你说的话也传开了**
> 你点王阿姨搭话，问她觉得对面那家怎么样。
> 她答的是**她记得的** —— 可能是三天前听来的，可能是亲眼见的（她会说清楚）。
> 而你自己随口说的一句话，也会被她带出去 ✓ —— 好坏都带走。

## 四、世界的四条格局

| # | 格局 | 它带来的东西 |
|---|---|---|
| 1 | **小店起步** —— 一家小超市，柜台交易 | 每次买卖都是**一次人和人的见面** ✓ 才有记忆/好感/传闻 |
| 2 | **玩家的视野也是有限的** | 玩家和 NPC 在同一个认识论层面 ✓ 天然的信息差与紧张感 |
| 3 | **小城 + 一条通往外面的路** | 外面不是另一张地图，而是**货源 / 商品 / 信息的来源**；挣够了钱去看 |
| 4 | **手机** | 有联系方式才能聊；顾客觉得你不错会加你 → **通讯录 = 你的情报网** |

## 五、紧张感从哪来

```
① 我不知道全貌        （视野有限 ✓）
② 我没时间全看        （四件事抢时间 ✓）
③ 我看到的可能是旧的  （世界在变，而记忆会过时 ✓）
```

**钱买不到"变强"** ✗ —— 它只能买三样：

```
· 买时间   雇人收银 → 你空出来去打听
· 买信息   电脑 / 雇人跑腿 → 你知道得更多
· 买脸面   请客 / 加薪 → 别人更记得你
→ 于是"花钱"和"分配时间"是同一件事的两面 ✓
```

## 六、系统设想（简版）

| 系统 | 一句话 |
|---|---|
| **认知** | 每个人有一个会**衰减**的记忆库；看世界是**有条件的**（第一次来 / 在闲逛 / 本地缺东西）|
| **传播** | 消息在人际间流动：谁愿意说 · 谁愿意听 · **传得越远越模糊**（精度逐级衰减，不是随机改数字）|
| **经济** | 劳动 → 产出 → 出口换钱 → 工资 → 消费，闭合成环；公司是经济单位，类型由建筑定 |
| **空间** | 逻辑上"谁跟谁能说话" = 在同一地点；表现上"走过去、站在一起、连一条线"|
| **时间** | 可暂停/快进；**快进 = 跳到不是快放**（引擎确定性，后台算完再给你看）|
| **玩家的眼睛** | 点开任何一个人，能看到他的需求、他记得什么、从谁那儿听来的、今天干了什么 |

## 七、已定的设计决定

| # | 决定 | 为什么 |
|---|---|---|
| 1 | 类型 = 店主经营，**爽点在声誉**（不是数字做大）| 内核唯一做得出来的是"人记得你" |
| 2 | 规模 = 小镇 **~40 人**（常客 15~30）| 声誉要"认得出来"；上限是你能记住多少张脸 |
| 3 | 地图 = **固定骨架**（玩家改不了）| "王阿姨每天路过你的店"靠的是稳定的空间关系 |
| 4 | **世界会自己演化**（对手开店 / 楼空 / 新居民搬来）| 把"可变"从"玩家是上帝"变成"世界在演化，你在其中" |
| 5 | 画面 = **2D 俯视** | 沉浸感来自"看穿一个人"，不来自镜头；2D↔2.5D 只是换投影层，可逆 |
| 6 | 玩家 = **一个有腿的 NPC**（能出门、能搭话、需求会掉）| 点击直接映射到引擎已有的端口动词 |
| 7 | **柜台交易**（不做自助超市）| 人和人见面才有记忆 / 好感 / 传闻 |
| 8 | **玩家的记忆不衰减，但世界会变** | 让玩家体验"**过时**"✓，不让他体验"遗忘"✗ |
| 9 | 传播分三层：**事实 / 传播 / 表达**；玩家是传播层里的一个节点 | 不能把对话做成一棵树 ✗ 它是"消息怎么流动" |
| 10 | 空间：**逻辑用"同一地点"，表现用锚点** | 逻辑零成本（引擎已如此），表现负责"不隔空" |
| 11 | **核心循环 = 分配你的一天** | 四件事互相抢时间，天然有取舍 |
| 12 | **钱只能买"时间、信息、脸面"** | 不能买装饰、不能买车买房 —— 否则后期是无底洞 |
| 13 | **快进 = 跳到，不是快放** | 引擎确定性 + 可无头跑；快放会撞 CPU 墙 |
| 14 | **快进有代价**：你的需求也在掉，**世界在变而你没看见** | 这是紧张感的来源 |
| 15 | **自动边界**：生理自动（吃 / 上厕所），**决策一律不自动** | 不让你死，但也不替你做任何有意义的决定 |

## 八、明确不做（反范围）

```
✗ 生活模拟：不买车 · 不买房自住 · 不逛街买衣服 · 不做装修审美
✗ 城市经营：玩家不修路 · 不盖楼 · 不规划地块
✗ 对话树 / 写死的台词（会盖掉 NPC 真实的记忆）
✗ 战斗 / 技能树 / 数值成长 / 收集要素
✗ 多人联机

✓ 玩家在城里的"生活"只有两件事：① 他的店   ② 他在城里的脸面
```

> **这个品类唯一的死法是"范围爆炸"。**
> 主策最重要的职责不是"想到更多玩法"，而是**把想加进来的东西挡回去**。

---

## 九、它和同类游戏的关系

拿 **Big Ambitions** 当最近的参照（同样的壳：固定小城 + 小店起步 + 摆货架 + 雇人）：

| | Big Ambitions 一类 | 我们 |
|---|---|---|
| 顾客是什么 | **人群**（统计量）—— 需求 = 营销 + 价格 + 商品吸引力算出来的数 | **每个人是一个 agent** |
| 顾客记忆 | 没有 | 会衰减、会被传闻污染 |
| "王阿姨再也不来了" | 不存在（只是客流数字掉了）| **是她脑子里的一行记忆** |
| 你的声誉 | 一个知名度数值 | 活在**别人记忆里**，你只能靠看见和听说来了解 |
| 内容量 | 上百种商品、一堆系统 | 少而深 —— 深度来自"你认识他们"，不是"你管的东西多" |

**所以我们不去挤【经营手感 + 内容量】那一头** ✗（那是巨量的内容工作）
**我们的机会在另一头：顾客少，但每个都是人。**
