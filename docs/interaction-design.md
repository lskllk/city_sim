# 交互与体验设计（⚠ 已并入 [UI 实现规格](ui-spec.md)）

> ## 这份文档已冻结归档 —— 实现请看 [ui-spec.md](ui-spec.md)
> 具体数值（时长表 / 状态表 / 触达规则）已并入 ui-spec 的 **§5 交互总表** 与 **§6 动效表**。
> 本文保留，作为**设计思路的记录**（为什么这么定），不再作为实现依据。
>
> 只谈**界面与手感**：能不能看到、能不能点到、点完有没有反应、动得对不对。
> 不涉及规则、数据、后端。

---

## 〇、一句话：现在三种东西长得一样，层级塌了

```
地图    = 世界      彩色、有质感
纸片    = 我的认知   名牌 / 气泡 / 情报条      ← 现在也是纸色
面板    = 我的操作   四角 HUD / 详情页          ← 现在也是纸色
```

三者同色同形，所以**分不清"这是世界""这是我知道的""这是我能点的"**。
下面所有条目都从这条展开。

---

## 一、三种视觉语言（先定这个，其余都好办）

| | 是什么 | 颜色 | 形状 | 阴影 | 动效 |
|---|---|---|---|---|---|
| **世界** | 房子 / 人 / 车 / 树 | 全彩 | 有机 | 落影 | 位移 + 呼吸 |
| **便签** | 名牌、气泡、情报条 | 纸色 | **直角 2px** | **无**（靠 1px 描边） | 只改透明度（= 新旧） |
| **面板** | HUD、详情页 | 纸色 | **大圆角 12px** | **有投影** | 进出 + 焦点 |

> **便签是贴在世界上的便利贴；面板是浮在世界之上的窗。**
> 现在两者都是"纸色 + 1px 边 + 小圆角"，所以看起来是同一类东西 —— 这是最该先修的一条。

---

## 二、触达：能不能点到

**现状问题**：缩到 0.42× 时，物品只剩 18×11 屏幕像素 —— 点不中；人更小。

```
· 热区不小于 28×28【屏幕】像素 —— 视觉可以小，热区不能小
  （缩放越小，热区相对放大：hitArea = max(视觉, 28 / cam.k)）
· 缩放下限从 0.42 抬到 0.5；到最远时【隐藏名牌】，只留建筑轮廓
· hover 必须有反应：描边 + 光标变手 + 名牌浮出    ← 现在完全没有
· 拖拽阈值 6px（有）；拖动时光标变"抓取/拖动中"
```

**hover 是当前最大的空洞**：鼠标划过地图，什么都不会变，玩家不知道什么能点。

---

## 三、反馈：点完知不知道

**现状问题**：点地面，人立刻开始走，但**点击本身没有任何标记**；走不过去也没有解释。

```
点击地面   → 落点一圈涟漪（160ms 扩散淡出）+ 路径虚线开始"长出来"
走不过去   → 目标画一个"挡"的记号（很短，200ms 淡出）
点中目标   → 目标描边脉冲一次（120ms）
点击成功   → 全部在 80ms 内给出第一反应，即使结果要等
到达       → 涟漪再收一次（"我到了"）
```

**规则：任何输入，80ms 内必须有视觉响应。** 这是手感的第一条。

---

## 四、状态：一个控件要有七种样子

```
默认 / 悬停 / 按下 / 禁用 / 空 / 选中 / 加载
```

- **禁用**：必须有原因（气泡里已有 `why` 文案 ✓），并且视觉上要"看得出是禁用"而不是"以为是坏的"
- **空**：不给文字，给形状（现在"没有这条情报"= 一条空轨道 ✓ 这个方向对）
- **选中**：地图上的目标 + 面板里对应的行要**互相呼应**（点地图 → 面板滚到那行）

---

## 五、动效：统一的时长表

**现状问题**：气泡硬出现硬消失；面板硬开硬关；缩放是跳的。

| 用途 | 时长 | 缓动 |
|---|---|---|
| 即时反馈（按下、涟漪） | 80–120ms | ease-out |
| 小过渡（hover、徽章切换） | 160–220ms | ease-out |
| 面板进出 | 220–280ms | cubic-bezier(.2,.8,.2,1) |
| 相机（跟随、回正） | 320ms | cubic-bezier(.2,.8,.2,1) |
| 昼夜 | 1200ms+ | linear |

**两条纪律**
```
① 颜色和透明度不要做主要过渡（会糊，看不出在动什么）—— 动位置和尺寸
② 同屏最多一个"在动的东西"抢注意力；同时动 = 没有重点
```

**具体要补的**：
```
· 气泡：从锚点弹出（scale .92→1 + 上浮 4px，180ms）
· 面板：整体 scale .98→1 + 背景 blur 0→7px（240ms）
· 快进：必须有"时间流过"的动效（数字滚动 / 日历翻页），不能硬出现
· 惊讶横幅：不要 7 秒自动消失 → 改成"停留到下一次交互"
```

## 六、层级：谁是焦点

```
面板打开时   →  地图不只是 blur，还要【压暗 8% + 去饱和 20%】
                （现在 blur 了但还是亮的，面板没有"浮起来"）
气泡是最高焦点 →  更亮的纸 + 唯一允许有明显投影的元素
名牌/徽章     →  背景级：不加投影，靠描边区分
玩家自己      →  唯一有"光晕"的东西（现在有 ✓）
```

---

## 七、节奏：时间感

```
· 时间在流逝要有非文字的表达：地图边缘一条极细的时间条 / 光影随时间移动
· 快进结束 = 一次"日历翻页"，不是弹窗
· 换天时：天色一变（已有）+ 一次极短的整屏呼吸（80ms）
```

---

## 八、一致性：一套图标、一套圆角、一套间距

**现状问题**：图标混了三种体系

```
emoji 字符   ⚙ ▣ ▤ ◧          ← 字体不同、大小不齐、颜色不受控
生 SVG       需求徽章           ← 好，但没有统一描边
纯字符       ● ❞ ∿             ← 来源记号
```

**统一成一套**：1.5px 描边、24×24 网格、`currentColor`。
来源记号（● ❞ ∿）可以保留为"语义记号"，但也要走同一套描边约定。

```
圆角   面板 12 / 卡片 8 / 控件 6 / 药丸 999      ← 只有这四种
间距   4 的倍数：4 / 8 / 12 / 16 / 24
字阶   11 / 12 / 13 / 15 / 20                   ← 不再有 11.5
描边   1px 线 = #ded7c8；2px = 焦点
```

## 十、优先级（我的建议顺序）

```
P0  便签 vs 面板的视觉分离         ← 三种东西现在长得一样，层级塌了
P0  hover 反馈                     ← 鼠标划过什么都不变，玩家不知道能点什么
P0  点击涟漪 + 80ms 内响应          ← 点完没反应 = 手感是空的
P1  热区最小 28px + 缩放下限 LOD    ← 缩小后点不中
P1  便签/面板的进出动效             ← 硬出现硬消失 = 廉价感
P2  图标系统统一                    ← emoji/SVG/字符 三套并存
P2  面板打开时地图压暗去饱和          ← 面板没有"浮起来"
P3  快进的"时间流过"动效             ← 跳过时间是核心动作，值得一次好动效
```

## 附：这份设计怎么验收

```
□ 三米外看画面，能分清"哪是世界、哪是我的便签、哪是我的面板"
□ 鼠标划过任何一个可点目标，都有反应
□ 任何点击，80ms 内都有第一反应
□ 同屏只有一个东西在动抢注意力
□ 图标只有一套（放大看描边一致）
□ 圆角只有四种，间距只有 4 的倍数
```
