## 一、基础

### 1.1 世界与相机

| 项 | 值 | 说明 |
|---|---|---|
| 世界尺寸 | `2048 × 1408` px | 逻辑像素，不是屏幕像素 |
| 导航网格 | `16` px / 格 | 128 × 88 格，A\* 用 |
| 相机缩放 | `k ∈ [0.42, 2.4]`，默认 1 | 滚轮，**缩放到光标**（光标下的世界点不动） |
| 相机平移 | 拖动，阈值 **6px**（<6px 算点击，不算拖动） | 拖动时**不跟随玩家** |
| 相机跟随 | 只在玩家走路时跟随，且不在拖动中 | |
| 世界 → 屏幕 | `screen = (world - cam) * k` | |
| 屏幕 → 世界 | `world = cam + screen / k` | |

**缩放必须"缩放到光标"**，不能缩放到中心 —— 这是手感的第一条，也是最容易做错的一条。

### 1.2 时间

| 项 | 值 |
|---|---|
| 一天 | `1440` tick（= 游戏分钟） |
| 1x | 60 游戏分钟 / 真实秒（一天 ≈ 24 真实秒） |
| 速度档 | `暂停 / 1x / 10x / 100x` |
| 走路速度 | `7` px / 游戏分钟（1x ≈ 420px/真实秒） |
| 营业时间 | 09:00 开门 / 19:00 关门（`540 / 1140`） |

**推进必须切成 ≤3 游戏分钟的小步**，否则一天里的事件会被跳过（"有人进店"这类要靠逐分钟判断）。

### 1.3 逻辑与表现的边界

```
行进 = 离散 tick 推进（模拟）
画面 = 每帧在 上一 tick 与 这一 tick 之间插值
```
**渲染帧永远不许驱动模拟。** 绝不在 `requestAnimationFrame` 里推进世界。

## 二、视觉语言 ★ 最要紧的一节

### 2.1 三种东西，必须一眼分得开

**这是整套 UI 的地基。三者同色同形 = 玩家不知道什么是世界、什么是他知道的、什么是他能点的。**

| | 是什么 | 颜色 | 形状 | 阴影 | 动效 |
|---|---|---|---|---|---|
| **世界** | 房子 / 人 / 车 / 树 / 路 | **全彩** | 有机、圆润 | 落影（右下偏移） | 位移 + 呼吸 |
| **便签** | 名牌、交互气泡、情报条 | 纸色 | **直角 4px** | **无**（靠 1px 描边） | 只改透明度（= 新旧） |
| **面板** | 四角 HUD、详情页 | 纸色 | **大圆角 12px** | **有投影** | 进出 + 焦点 |

> **便签是贴在世界上的便利贴；面板是浮在世界之上的窗。**

### 2.2 色板

```
纸（面板 / 便签）
  --paper    #f7f4ee    面板底、便签底
  --paper2   #efebe1    次级底（HUD 条、面板头）
  --paper3   #e6e0d2    轨道、开关槽、空位

墨
  --ink      #26221c    主文字
  --ink2     #7a7264    次文字、标签、说明

线
  --line     #ded7c8    1px 分隔／描边
  焦点描边   2px = --hi 或 --ink2

语义色（只允许这三个做"有含义的颜色"）
  --hi       #b4552d    强调：钱 / 警告 / 选中 / 进度 / 我自己
  --ok       #4a7358    好：今天来过 / 情报新鲜 / 我自己经手的
  --warn     #9b6f16    注意：旧了 / 不太确定

地图（世界，饱和；UI 不许跟它抢）
  草地       #6d8a52    草地深 #5f7a47
  沥青       #4c4a4a    人行道 #b8b3a6    标线 #e9e5da
  屋顶·砖    #8c5b48    屋顶·灰 #6b7176   屋顶·瓦 #7a6a5a
  我的家外墙  #8a6a4e    地板    #e8dfc9
  树         #4f7a45    树干深 #3d6236
  窗（夜）    #ecc579    夜色叠加 #0d2340 (multiply, ≤55%)
```

**纪律**：UI 不许为了"配地图"加饱和色。**地图越热闹，UI 越要像一张安静的纸。**

### 2.3 字阶 / 圆角 / 间距 / 描边（❄ 冻结）

> ⚠ 参考实现里有 9 种字号、9 种圆角 —— **那是漂移，实现时按下面这张表来**。

```
字号（6 档，只有这 6 个）
  10px   微标：来源记号 · 单位 · 序号 · 时间
  11px   辅助：说明文字 · 计数 · 上限提示
  12px   正文小：HUD 标签 · 卡片名 · 列表行 · 按钮
  13px   正文：面板正文 · 表格 · 标题
  16px   小标题：详情页 h2 · 关系页名字
  20px   大数字：金钱 · 来过几次

圆角（4 种，只有这 4 个）
  4px    便签／小标签（名牌、气泡内小块）
  8px    卡片／控件（列表行、物品卡、按钮块）
  12px   面板／气泡（详情页、四角 HUD、交互气泡）
  999px  药丸按钮（时间档位、动作按钮、入口）

间距（4 的倍数，只有这 6 个）
  2 / 4 / 8 / 12 / 16 / 24

描边
  1px   常态分隔／描边（--line）
  1.5px 地图上的小元件（名牌、徽章）
  2px   焦点／选中
```

### 2.4 标注层：文字一律不进缩放层 ★

> 这一节是**冻结之后**因为一个 bug 补进来的，是结构性决定，不是实现细节。

**故障现象**：放大地图时，气泡和物品名反而变糊（缩小没事）。

**根因**：文字原本住在被缩放的容器 `#world` 里，靠 `scale(1/k)` 反向缩放抵消。
只要文字在缩放容器里，就得依赖浏览器的栅格化策略 ——
一旦那个容器被缓存成 GPU 纹理（`will-change: transform` 会强烈诱导这件事），
放大就变成"把 1× 的纹理拉大 2.4 倍"，小字全碎。
**指纹：放大变糊、缩小没事**（缩小是缩小采样）。

**规矩（两条，都要）**

```
① 缩放容器上禁止写 will-change: transform
   （也不要用 translateZ(0) / backface-visibility 之类去"优化"它）

② 所有【文字】住在屏幕空间标注层 #labels 里，不进 #world
   名牌 / 人名 / 需求徽章 / 交互气泡 → #labels
   地面 / 路 / 建筑 / 人 / 物品 → #world（形状随缩放，没问题）

   位置每帧投影：  screen = (world − cam) × k + viewport 的页面偏移
   字号永远 1:1  →  任何缩放都锐，与浏览器策略无关
```

```
#labels{ position:fixed; inset:0; pointer-events:none; z-index:5 }
#labels>*{ position:absolute; left:0; top:0 }
#labels .bub{ pointer-events:auto }        ← 只有气泡可点，其余穿透给地图
```

**每帧按需建 / 改 / 删**（按 id 对齐，不是每帧重建 —— 重建会冲掉 hover 和按钮点击）。

**居中锚点必须和位置写在同一条内联 transform 里**，否则 CSS 里的
`translate(-50%)` 会被内联 transform 覆盖掉：

```js
el.style.transform = `translate(${x}px,${y}px) translate(-50%, ${anchor})`;
//                                        anchor: 名牌 "0%" · 人名/徽章/气泡 "-100%"
```

**LOD**：物品名是"写在物件上"的（在世界里），`k < 0.6` 时整体不画，别留一团糊字。

### 2.5 层级（z-index）

```
世界层（在 #world 里，随相机缩放）
   2  建筑（世界 · 建筑）
   6  物品（世界 · 物品）
   7  名牌（世界 · 建筑名牌）
   8  人物（世界 · 人物）
   9  队列编号点 / 导航路径虚线
  50  交互气泡 ★ 世界内最高焦点

屏幕层（fixed）
   2  夜色叠加（multiply）
   3  雨
   5  ★ 标注层 #labels（名牌 / 人名 / 徽章 / 交互气泡）—— 见 §2.4
  10  四角 HUD
  20  详情页虚化层
  21  详情页面板
  30  快进摘要
```

### 3.2 详情页（前图层）

```
虚化层 #veil   position:fixed; inset:0; z:20
               background: rgba(233,229,219,.42)
               backdrop-filter: blur(7px) saturate(.75)
               点击 = 关闭

面板 #sheet    position:fixed; left:50% top:50%; translate(-50%,-50%); z:21
               宽 min(1020px, 86vw)   高 min(660px, 82vh)
               背景 --paper（**不透明**）· 1px --line · 圆角 12
               投影 0 24px 70px rgba(0,0,0,.2)
  窄版 .narrow  宽 min(560px, 88vw)   高 auto（用于设置/存档/关系页/我的家）

结构          头（h2 16px + 副标题 12px --ink2 + 关闭药丸）
              标签行（可选，2px 下划线高亮）
              内容区（overflow:auto，padding 14 20 20）
```

**打开详情页 = 暂停世界**，关闭时**恢复原来的档位**（如果打开前就是暂停，关掉还是暂停）。

### 3.3 缩放下限与 LOD

```
k ≥ 0.7   显示人物名牌
k < 0.7   隐藏人物名牌（避免文字糊成一团）
k < 0.65  隐藏建筑名牌上的细节（只留名字）
建筑图标在 k=0.42 时仍要能认出是房子
```

## 四、组件清单

> 组件编号 `C-xx` 用在本文与实现注释里。**「占位」一栏指向 §8。**

### C-01 左上 · 玩家状态卡

```
┌──────────────────────┐
│ 陈知远                │   12px --ink2，玩家自己设的名字（设置里改，≤8字）
│ ¥412  今天 -38        │   20px 粗 + 11px，负数用 --hi
│ 饥 ▓▓▓▓░  52          │   三条需求：标签 11px --ink2 + 4px 轨道 + 数值 11px
│ 精 ▓▓▓░░  38          │   值 <30% → 轨道填色转 --hi
│ 憋 ▓▓░░░  22          │
│ 自动生理 开 —— ……      │   10px --ink2；自动执行中 → --hi
└──────────────────────┘
```

| | |
|---|---|
| **数据** | 玩家名字 · 现金 · 今日净变化 · 三条需求信号 |
| **状态** | 正常 / 偏低（<30%，填色 --hi）/ 自动执行中（文案转 --hi） |
| **交互** | 无（纯显示） |
| **纪律** | **别人的钱和需求不许显示**（F 类不可得，见 [信息设计](ui-design.md) §5）；这里只有"我自己的" |

### C-02 左上 · 当前动作 + 队列 ★

```
───────────────────────────────
➜ 走去 街角水果铺          [✕]     12px 粗 + 取消
▓▓▓▓▓▓░░░░░░                      3px 进度条，--hi
───────────────────────────────
排队 2                             10px --ink2
(1) 👁 确认 梨 的价         [✕]     序号 13px 圆 + 图标 + 12px 标签
(2) ➜ 去加工厂              [✕]
```

| | |
|---|---|
| **数据** | 当前动作（类型/标签/目标/进度）· 队列（有序，≤8 条） |
| **状态** | 空闲（只写"站着"）/ 有动作 / 有队列 / 刚完成（打勾划掉 800ms 后自动消失） |
| **交互** | 当前动作的 ✕ = 取消（自动接队列下一条）· 队列条的 ✕ = 只删这一条 · `X` 键 = 取消 |
| **动效** | 进度条 `width .12s linear`；**结构只在变化时重建**（每帧重建会冲掉 hover） |
| **纪律** | 只有**当前那一条**有进度条 —— 一眼看出"我在干什么、做到哪了" |

### C-07 世界 · 建筑（含名牌 + 知识等级）★

**结构**：外壳 = 地板层 + 屋顶层（屋顶可淡出）+ 名牌（纸片，挂在建筑下方）

**知识等级** —— 用**饱和度**表达"我对这里面知道多少"：

| 等级 | 条件 | 屋顶/地板 | 名牌 |
|---|---|---|---|
| `lv0` 没进去过 | 没有任何该地情报 | `filter: saturate(.12) brightness(1.07)` | **只给名字** + 一条**空轨道** |
| `lv1` 记旧了 | 最新情报 > 1 天 | `filter: saturate(.5) sepia(.28)` | 名字 + 褪色的精度条 |
| `lv2` 新鲜 | 最新情报 ≤ 1 天 | 全彩 | 名字 + 精度条 |

**名牌（纸片）**：`--paper` 底 · 1px `--line` · 圆角 4 · 11px · 名字 600 粗 + 精度区间条

**屋顶 LOD**（"走进去看室内"）：
```
在屋里 + 相机近   → 屋顶 opacity → 0    （k ≥ 0.95 全透明）
在屋里 + 相机远   → 屋顶 opacity → 1    （k ≤ 0.55 不透明）
不在屋里          → opacity 1
过渡 .28s
```
> **不让玩家看穿别人的房子**：屋顶只有"我在里面"时才淡出。

**交互**：`hover` → 描边加深 · 点击 → 出 C-10 气泡

**占位**：建筑贴图（屋顶 + 立面揭示 + 门口），规格见 §8 / [美术方向](art-direction.md) §5

### C-08 世界 · 人物（含名牌 + 需求徽章）

```
        (碗)          ← 需求徽章 16px 圆，见下表
        王阿姨         ← 名牌（纸片，10px），不认识就不给
         🧍           ← 人物（脚底锚点，18×24 @1x）
```

| | |
|---|---|
| **可见规则** | 只有**我在场**才画：同一栋楼 ∨ 他走在路上。**他在楼里我在外面 → 不画**（决定 #10） |
| **认识** | 认识 → 有名字 + 绿色；不认识 → 无名 + 灰 |
| **徽章** | 饿 = 碗（--hi）· 困 = 闪电（#6b7f9a）· 憋 = 水滴（#5a7f96）· **在门口犹豫 = `?`**（#a8761c） |
| **朝向** | 走路时按 x 方向水平镜像 |
| **交互** | 点击 → C-17 关系页 |
| **占位** | ⟦占位⟧ 现在是 SVG 画的头+身体+头发。**要求：脚底锚点，18×24 @1x，4 向 + 走 4 帧 + 站 1 帧** |

> **需求用徽章 + 姿态表达，不写 `activity: "来我店里"`。**

### C-09 世界 · 物品

货架 / 床 / 餐桌 / 马桶 / 工位。矩形 + 名称。分类配色：

```
goods    #d9b06a   货（可买）
food     #cb8f66   吃的
bed      #8d9db0   睡
fixture  #a9a396   家具

## 五、交互总表

### 5.1 鼠标

| 操作 | 结果 |
|---|---|
| 点击地面 | **排队**"走到这里"（队列空时立即开始） |
| `Shift` + 点击地面 | 插到**队首**（下一个就做） |
| 点击建筑 | 出 C-10 气泡（里面是"走进去 / 公司管理"） |
| 点击物品 | 出 C-10 气泡（按两个闸门给动作） |
| 点击人物 | 打开关系页（**并暂停世界**） |
| 点击队列编号点 | 取消当前动作 |
| 点击气泡内部 | 交给按钮自己处理（**不重新派发**） |
| 拖动 | 平移相机（阈值 6px，<6px 才算点击） |
| 滚轮 | **缩放到光标** |
| `hover` 任何可点目标 | **必须有反应**（描边 + 光标 + 名牌浮出） |

> ★ **不许依赖 `click` 事件派发目标。**
> 血泪教训：如果用 `setPointerCapture`，指针被捕获后 `click` 的目标会变成捕获元素，
> 所有 `onclick` 都不会触发，而且看起来"只有某个东西点不动"，极难排查。
> **正确做法**：`pointerdown` 记起点 → `pointermove/up` 挂 `window` →
> 在 `pointerup` 里用 `document.elementFromPoint` + `closest("[data-t]")` 自己派发。

## 六、动效表

**时长只有这几档，缓动只有这两种。**

| 用途 | 时长 | 缓动 |
|---|---|---|
| 即时反馈（按下、涟漪） | 80–120ms | ease-out |
| 小过渡（hover、徽章切换） | 140–160ms | ease-out |
| 屋顶淡出 / 夜间 | 280ms / 1200ms | linear |
| 面板进出 | 220–280ms | cubic-bezier(.2,.8,.2,1) |
| 相机（跟随、回正） | 320ms | cubic-bezier(.2,.8,.2,1) |
| 进度条 | 120ms | linear |

**两条纪律**

① 颜色和透明度不做主要过渡（会糊）—— 动【位置】和【尺寸】

```

## 七、信息呈现规则（P6 的落地）

### 7.1 文字 → 形状 对照表

| 信息 | ✗ 别写 | ✓ 画成 |
|---|---|---|
| 我没进去过这家店 | `？ 还没去过` | 建筑**去饱和**（`saturate(.12)`）+ 名牌上一条**空轨道** |
| 我记的价旧了 | `6 天前` | 建筑**泛黄**（`saturate(.5) sepia(.28)`） |
| 这个价我有多确定 | `不到5块` | **区间条**：精准=一个点，模糊=一段宽带 |
| 他是听说的 | `打听` | **引号记号**（亲眼=实心，传闻=虚线+波浪） |
| 他饿了 | `activity: "来我店里"` | **碗徽章 + 姿态** |
| 这人是熟客 | `熟客留存 61%` | **进门直接走向柜台**；生人**在门口犹豫**（冒 `?`） |
| 谁很久没来了 | `上次来 13 天前` | **常客墙最右边那张卡变灰、虚线、热度条几乎空** |
| 我不在场的那笔生意 | `我在: 不在` | **小票变虚线 + 60% 透明** |
| 我的声誉 | 声誉分 78 | **谁在门口犹豫、谁直接进门**（+ 账本） |
| 时间在流逝 | 只有时钟 | **昼夜色调 + 窗光** |

### 7.2 必须精确、不许模糊化

```
钱 · 时间 · 名字 · 库存 · 来过几次 · 上次几天前（放在 tooltip 里）
```
这些模糊了反而难受。**原则：世界表现优先，但"必须不歧义"的仍然用数字。**

### 7.3 「？」只能表示"可得但还没得"

```
没去过的店        → 名牌给【空轨道】+ 名字（名字全可见，是常识）
别人的口袋有多少钱 → 【不画】（F 类不可得）
```
**不可得的东西不画，连"？"都不给** —— 否则玩家会把一生花在点一个永远打不开的门上。

### 7.4 常客墙四级 · 7.5 精度档带宽 · 7.6 知识三级

见 C-15 / C-23 / C-07。

> ⚠ **演示数据必须把差异拉开**：常客的"上次来"要有 今天 / 1 天 / 3 天 / 13 天的梯度，
> 否则常客墙整排一样亮，等于没有信息。

| 树 / 车 | CSS 圆形 / 圆角矩形 | `assets/props/*` |
| 建筑 | CSS 色块 + 描边 | `assets/bld/*.png` + 同名 JSON |
| 室内地板 | CSS 色块 | 室内地板贴图（物品已经有了） |
| **物品（货 / 家具）** | ✅ **已生成** | `art/out/items/` —— 9 件 × (世界俯视 + 图标正视) + 3 张空态 |
| 物品【空态】 | — | ✅ "卖光了"用形状表达，不写字（`*_empty.svg`） |
| 人物 | `personSVG()` 里画的 SVG | `assets/people/*`（同一个函数换成 `<img>`） |
| 小头像 | `miniPerson()` | 同上，复用人物资产的头像裁切 |
| 需求徽章 | 内联 SVG（碗/闪电/水滴） | 可保留（是图标不是插画） |
| 所有图标 | `ICON{}` 里的内联 SVG | 统一图标系统（1.5px 描边 / 24 网格 / currentColor） |

### 8.3 内容占位（不是美术，是数据/文案）

```
· 15 个 NPC 的名字 / 脸 / 性格 / 作息 / 熟人关系   （造人器或手写）
· 3~5 种商品、价格、保质期、affordance
· 场景里的建筑名（吵吵小店 · 街角水果铺 …）—— 现在是编的
· 玩家默认名（现在是"陈知远"）
· 打听的回答模板池（persona × mood × 精度档）
```

## 九、迁到正式前端（PixiJS）

### 9.1 分工（铁律）

```
PixiJS  →  世界层（地面/路/建筑/人/物品/相机/连线/选中框）
HTML    →  便签层（名牌/气泡）+ 面板层（四角 HUD / 详情页）
```
> **面板和气泡绝不进 canvas。** 它们里面是密集文本、换行、按钮、"褪色代表过时"的 CSS 规则 ——
> 这是这个游戏的玩法本体，画进 canvas 是自虐。

### 9.2 从技术验证里学到的五条

```
① 静态层【烘焙】     地面+路只画一次，烘成一张 RenderTexture。永远别在 ticker 里重画。
② sync(world) 对齐   按 id 增/改/删，不是每帧 removeChildren + 重建。
③ 外观规则单一出口   tintOf(e) / alphaOf(e) —— "这条信息有多旧 → 什么颜色"只写在一处。
④ 缩放到光标         cam.x = wx − px/k（数学就这一行，但错了手感全废）
⑤ 文字成本           每个 Text = 一张纹理。数量大时按缩放/距离【缓建】，不是只设 visible

⑥ 【PixiJS 对应做法】上面 §2.4 在 Pixi 里是：世界只画图形和精灵,
   名牌/气泡用一个 HTML 覆盖层盖在 canvas 上, 每帧把世界坐标投影成屏幕坐标。
   不要在 Pixi 里用 container.scale 反向缩放文字去抵消相机缩放 —— 同一个坑。
```

### 9.3 不许做

```
✗ 在渲染帧里推进模拟
✗ 用 CSS 的 class 去表达世界状态（世界状态进 Pixi，用 tintOf 一个函数）
✗ 把名牌/气泡画进 canvas（除非确认 DOM 覆盖层的性能真的不够）
✗ 为了"配地图"给 UI 加饱和色
```

## 十、验收清单

```
【视觉语言】
□ 三米外看画面，能分清"哪是世界、哪是便签、哪是我的面板"
□ 地图是全彩的，UI 是安静的纸
□ 字号只有 6 档，圆角只有 4 种，间距都是 4 的倍数
□ 图标只有一套（放大看描边一致，没有 emoji 混在里面）

【信息纪律】
□ 每个数字旁边都能说出来源 + 时间；说不出的删掉了
□ 没有任何一处显示"此刻的真值"（别人的钱/需求/记忆/打算）
□ 「？」只用在"可得但还没得"，不可得的【不画】
□ 笔记本不会自己更新
□ 常客墙的四级亮度是有梯度的（演示数据把差异拉开了）
□ 精度 <4 档时不给确定数字，但仍然有形状 + tooltip

【交互动效】
□ 鼠标划过任何可点目标都有反应
□ 任何点击 80ms 内都有第一反应
□ 拖动（>6px）不触发点击
□ 滚轮缩放是"缩放到光标"
□ 气泡挂在世界坐标上（拖动地图跟着走）
□ 【放大到最大】时，气泡字 / 名牌字 / 物品字都是锐的（不糊）← 见 §2.4
□ 缩放容器上没有 will-change: transform
□ 打开详情页 → 暂停；关掉 → 恢复【原档位】
□ 同屏只有一个东西在动抢注意力

【玩法手感】
□ 点 = 排队（不打断）；Shift+点 = 插队
□ 取消当前动作会自动接队列下一条
□ 自动生理抢占后，被打断的那条回到队首
□ 队列在地图上有编号点
□ 走进去 = 亲眼看见 → 笔记本能被刷新（这条闭环通）
□ 用家里的东西有过程（进度条），不是瞬间生效
□ 在家 / 不在家 的面板状态一眼看得出（实心 vs 虚线）

【产出】
□ 演示数据与真实数据的形状一致（换数据源不改界面）
□ 所有 ⟦占位⟧ 都能不改代码替换成美术资产
```
